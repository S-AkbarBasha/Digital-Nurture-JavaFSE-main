EX 4

Built-in Directives

Structural (@if, @for, @switch) and Attribute (NgClass, NgStyle) directives

1️⃣ @if / @else — Conditional Rendering

@if (isLoggedIn) {
✅ Welcome! You are logged in.
} @else {

❌ Please login to continue.

}

2️⃣ @for — List Rendering

@for (country of countries; track country.code; let i = $index) { }
#FlagCodeCountry
{{ i + 1 }} {{ country.flag }} {{ country.code }} {{ country.name }}

3️⃣ @switch — Multi-branch Condition

@for (s of statuses; track s) { }
@switch (status) { @case ('active') {
🟢 Status: ACTIVE — Service is running
} @case ('inactive') {

🔴 Status: INACTIVE — Service is stopped

} @case ('pending') {

🟡 Status: PENDING — Service is starting

} }
